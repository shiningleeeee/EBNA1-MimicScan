# Step 3 — 短基序通道的最后一个可判定性测试

生成时间：2026-10-22 · 远端 `/workspace/PH-Mimic`
数据：UniProt release 2026_03（2026-09-02），EBNA1 `P03211`（641 aa），Homo sapiens reviewed 20,431 条

## 0. 一句话结论

**在 6–10 aa 的分辨率上，EBNA1 与人类蛋白组的短基序共享量，和"保留局部组成的洗牌序列"完全分不开（12 个检验，最小 p = 0.118，Bonferroni 阈值 0.0042）。序列通道到此为止：不存在能被组成对照零模型支持的候选。**

## 1. 这次测的是什么

Biomni 与我自己前两步做的所有"命中"，都是在**全库比对 / 种子延伸**层面统计的。它们的共同弱点是：长比对天然占优，而低复杂度区（Gly-Ala、SPR、PG 富集）会制造大量假命中。

这一步换一个尺度问问题：

> EBNA1 的 6/7/8/9/10-mer，在人类蛋白组里出现得比"同位置同组成但顺序打乱"的 EBNA1 更多吗？

这是**唯一一个与比对长度无关、与比对打分无关**的检验：它只看"特定的短序列排列"是否比"同样的氨基酸组成"更常出现。如果答案是否定的，那么所有基于相似度的候选排名都只是组成的函数，不携带残基顺序信息。

## 2. 方法（可复现）

工具：新写 `src/motif_mine.c`（无外部依赖，gcc -O3 -pthread），pigeonhole 分段索引 + 逐段精确拼装。

- 基序长度 L ∈ {6,7,8,9,10}；允许错配 d：L≤6 → 1，L≤9 → 2，L=10 → 3
  一致率下限分别是 5/6、5/7、6/8、7/9、**7/10**。
  L=10 必须给 d=3，否则会漏掉已发表的 ANO2 模拟（`PGAIEQGPAD` ↔ `PGDIELGPLD`，正好 7/10）。
- **组成门**：不同残基数 ≥ 60%·L，且单个残基占比 ≤ 40%·L。用来剔除 `GGGGGG`、`PGPGPG` 这类无信息基序。
- **零模型**：把 EBNA1 在 20-aa 窗口内做保组成洗牌（Fisher-Yates，种子固定 42），重扫一遍。B=50。
  窗口内洗牌 = 在任何 ≤20 aa 的尺度上，组成完全相同、顺序被破坏。这正是我们要否证的东西。
- 真实序列 run 0，洗牌 run 1–50，共用同一套索引，逐格计数。

命令：

```bash
gcc -O3 -march=native -pthread -o env/bin/motif_mine src/motif_mine.c
env/bin/motif_mine --query data/cache/P03211.fasta \
  --db data/cache/human_swissprot.fasta \
  --out-prefix reports/gated --null-b 50 \
  --lens 6,7,8,9,10 --gate 1 --threads 5
env/venv/bin/python src/11_motif_null_summary.py   # → reports/gated_summary.tsv
```

耗时 2 分 14 秒（5 张索引，10.4M–9.0M 个过门窗口/张，51 遍扫描）。

## 5. 这一步否证了什么、没否证什么

**否证了**：
- "EBNA1 的短基序在人类蛋白组里异常富集"——不成立，任何 L 上都没有超额。
- 因此，任何按"短基序一致数"给候选排序的做法（包括我 Step 2 的规则 R 和 Biomni 的 E_emp 排序）都没法把顺序信息与组成信息分开。

**没否证**：
- 三个已发表模拟本身是真的（抗体结合是实验事实）。但它们所在的 EBNA1 386–440 区段是 SPR-rich / PGA-rich 低复杂度区，其"相似性"在组成对照下不特殊。换句话说：**这三个 mimics 是被抗体实验发现的，不是被序列相似性发现的**——这也解释了为什么所有序列统计量（我的三套 + Biomni 的 E_emp/E_band）对它们都不敏感。
- 组成门本身会杀掉部分已发表基序（`SPPRRPP`：不同残基 4/7 = 57% < 60%，P 占 3/7 = 43% > 40% → 被门滤掉）。这是**已知的、故意的**取舍：诚实地说，去掉这道门后一切都会被低复杂度区淹没。

## 6. 现在的处境（给决策用）

序列通道已经用三种互相独立的零模型测过：

| 零模型 | 结论 |
|---|---|
| 全局保组成洗牌，比对计数（Biomni N0/N1/N2 式） | 真实 = 1.23×，四个已发表基准全部落在噪声里 |
| 窗口保组成洗牌（10/20/40 aa），MMseqs2 E-value | p = 0.176 / 0.170 / 0.140，**顺序无信号** |
| 窗口保组成洗牌（20 aa），短基序 6–10-mer 计数 | p ≥ 0.118，**顺序无信号** |

三条路、三种统计量、同一个答案。**继续在序列通道上调过滤器，只会继续生产组成假象。**
